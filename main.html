1 Overview

This report estimates a reduced-form VAR for the Italian electricity market and identifies structural shocks via sign restrictions, following Kilian & Lütkepohl (2017, Ch. 13): Haar-uniform random rotations of the Cholesky factor (via QR decomposition), an admissible-set search over the configured sign restrictions, and Fry & Pagan (2011) median-target (MT) selection for the reported impulse responses. Confidence bands come from a frequentist residual bootstrap (Inoue & Kilian, 2013) that re-runs the entire identification search inside every replication.

Every modeling choice below (variables, transformations, lags, restrictions, bootstrap settings) is read from 00_config.R – that is the only file that needs editing to change the analysis.

#' Draw one plot into `plots_dir/<variable id>/<name>.png` instead of the
#' report -- the report shows the combined grids, the per-variable files are
#' for use outside it.
save_plot <- function(id, name, draw) {
  dir <- file.path(config$paths$plots_dir, id)
  dir.create(dir, showWarnings = FALSE, recursive = TRUE)
  grDevices::png(file.path(dir, paste0(name, ".png")),
                 width = 7, height = 4.5, units = "in", res = 150)
  on.exit(grDevices::dev.off())
  draw()
}

plot_series <- function(v) {
  plot(raw_data$date, raw_data[[v$id]], type = "l", col = "steelblue",
       xlab = "", ylab = v$label, main = v$label)

4 VAR estimation

Variables are split into endogenous/exogenous automatically from each variable’s role in config. Eleven monthly seasonal dummies (Feb-Dec; Jan is the reference month) are always appended to the exogenous block to control for calendar seasonality. The lag order follows config$lag_selection (fixed or auto via vars::VARselect()).

6 Identification

Structural shocks are identified via sign restrictions read generically from config$shocks – adding a shock or a restriction requires no changes to 05_sign_restrictions.R. For each of config$identification$n_draws Haar-uniform random rotations \(Q\), the structural impact matrix \(B_0 = P Q\) is checked against every configured shock’s sign restrictions; admissible draws are kept, and the Fry-Pagan median-target draw (the single admissible model closest to the pointwise median IRF) is reported, rather than the pointwise median itself.

ident <- identify_sign_restrictions(var_out$fit, config)

cat(sprintf(
  "Acceptance rate: %.2f%% (%d / %d rotations admissible).\n",
  100 * ident$draws$acceptance_rate, ident$draws$n_accepted, ident$draws$n_draws
))
## Acceptance rate: 2.08% (208 / 10000 rotations admissible).

The acceptance rate is a diagnostic of how informative the restrictions are: a low rate means the restrictions rule out most of the rotation space (informative, but a non-refutability check worth keeping in mind); a rate near 100% means the restrictions barely bind.

restr_table <- purrr::map_dfr(config$shocks, function(s) {
  purrr::imap_dfr(s$restrictions, function(r, var_id) {
    tibble::tibble(shock = s$name, variable = var_id, sign = r$sign,
                    horizons = paste(range(r$horizons), collapse = ":"))
  })
})

7 Bootstrap

Frequentist confidence bands (Inoue & Kilian, 2013): the reduced-form VAR residuals are resampled, the sample is rebuilt recursively, the VAR is re-estimated, and the entire identification search above is re-run inside every replication – not just a coefficient resample.

boot_out <- run_bootstrap(var_out$fit, var_out$endo, var_out$p, config)

cat(sprintf(
  "Bootstrap: %d replications, %d succeeded, %d found no admissible rotation.\n",
  boot_out$n_boot, boot_out$n_ok, boot_out$n_failed
))
## Bootstrap: 1000 replications, 1000 succeeded, 0 found no admissible rotation.
cat(sprintf(
  "Mean acceptance rate across successful replications: %.2f%%.\n",
  100 * mean(boot_out$boot_acceptance_rates)
))
## Mean acceptance rate across successful replications: 2.01%.
hist(100 * boot_out$boot_acceptance_rates, breaks = 15, col = "steelblue",

     xlab = "Acceptance rate (%)")

8 Results

Median-target impulse responses with 68% bootstrap confidence bands.

plot_irf_grid <- function(mt_irf, bands, var_names, shock_names, var_labels) {
  n_shocks <- length(shock_names)
  n_vars <- length(var_names)
  h <- seq_len(dim(mt_irf)[3]) - 1

  old_par <- par(mfrow = c(n_vars, n_shocks), mar = c(3, 4, 2, 1))
  on.exit(par(old_par))

  for (v in seq_len(n_vars)) {
    for (s in seq_len(n_shocks)) {
      point <- mt_irf[v, s, ]
      lo <- bands$lower[v, s, ]
      hi <- bands$upper[v, s, ]

      plot(h, point, type = "n", ylim = range(c(point, lo, hi), na.rm = TRUE),
           xlab = "", ylab = var_labels[v],
           main = if (v == 1) shock_names[s] else "")
      polygon(c(h, rev(h)), c(lo, rev(hi)),
              col = grDevices::adjustcolor("steelblue", alpha.f = 0.25), border = NA)
      lines(h, point, col = "steelblue", lwd = 2)
      abline(h = 0, lty = 2, col = "grey40")
    }
  }
}

var_labels <- purrr::map_chr(config$variables, "label")
names(var_labels) <- purrr::map_chr(config$variables, "id")
