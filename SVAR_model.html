6. ADF Stationarity Tests

The Augmented Dickey-Fuller test has this null hypothesis:

  • the variable has a unit root, so it is not stationary.

If the p-value is below 0.05, we reject the null and treat the variable as stationary. This is still a preliminary check, not the final modelling decision. I use 12 lags because the data are monthly.

adf_variables <- get_catalogue_model_columns(variable_catalogue)

adf_results <- run_adf_tests(
  svar_data,
  variables = adf_variables,
  lags = experiment_config$adf_lag
)

11. Recursive One-Step PUN Forecast Evaluation

For point forecasts, the SVAR and the reduced-form VAR imply the same conditional mean. The recursive exercise therefore re-estimates the reduced-form VAR each month and then converts the one-step PUN forecasts back to levels.

The random walk benchmark is:

  • next PUN level equals the last observed PUN level.

The Clark-West test compares the squared forecast errors of the SVAR and the random walk with a nesting adjustment. The null hypothesis is equal predictive accuracy.

recursive_forecasts <- run_recursive_forecasts(
  data = svar_input,
  svar_variables = svar_variables,
  exogenous_variables = exogenous_variables,
  selected_lag = selected_lag,
  catalogue = variable_catalogue,
  config = experiment_config
)

pun_forecast_accuracy <- forecast_accuracy_table(
